# SENTINEL // AI Security Lab

AI의 도움을 받아 제작한 사이버 보안 콘셉트 포트폴리오 데모 웹사이트입니다.

## 특징
- 보안 대시보드 스타일 UI
- 위험 점수 시뮬레이션
- 로그인 실패 / 차단 / API 이벤트 피드
- 네트워크 트래픽 시각화
- 반응형 레이아웃
- HTML / CSS / JavaScript만으로 동작

## 실행 방법
`index.html` 파일을 브라우저에서 열면 바로 실행됩니다.
VS Code의 Live Server를 사용해도 됩니다.

## 주의
화면에 표시되는 위험 점수, IP, 이벤트 값은 모두 데모용 시뮬레이션 데이터입니다.
실제 보안 스캔이나 실제 공격 탐지 기능은 포함하지 않습니다.

## 포트폴리오 설명 예시
AI의 도움을 받아 보안 로그와 이벤트 흐름을 시각적으로 표현한 인터랙티브 웹사이트를 제작했습니다. 구조와 동작을 직접 확인하면서 UI 구성, 이벤트 처리, 상태 변화 표현 방식을 학습했습니다.
